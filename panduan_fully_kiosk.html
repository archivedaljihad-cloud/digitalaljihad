1 Mengatasi Tampilan Kebesaran / Terpotong (TV 55" – 75" / 4K)

Penyebab: Sistem Android TV secara bawaan memiliki kepadatan piksel (DPI) tinggi sehingga WebView otomatis melakukan auto zoom-in 150%–200%. Atur opsi di bawah agar tampilan kembali pas dan proporsional:

Menu di Fully Kiosk Nilai yang Dipilih Fungsi & Catatan
Web Content >
Initial Scale		 75% atau 50% KUNCI UTAMA: Menurunkan zoom webview. Untuk TV 55"–75", coba 75% lebih dulu. Jika masih terasa terpotong di tepi, gunakan 50%.
Web Content >
Enable Viewport Meta Tag		 ENABLE (ON) Memerintahkan browser mematuhi skala responsif yang sudah dibuat di kodingan website masjid.
Web Content >
Text Zoom		 100% Mengunci ukuran teks agar tidak dibesarkan paksa oleh sistem Android TV.
Web Browsing >
View Mode		 Desktop Mode WAJIB: Memastikan TV dirender sebagai layar lebar PC/TV (16:9), bukan mode handphone (Mobile).

2 Pengaturan Cache (Agar Data Selalu Realtime dari Cloudflare)

Mencegah TV menahan cache file lama sehingga perubahan jadwal sholat, pengumuman, dan petugas Jum'at langsung tayang seketika.

Menu di Fully Kiosk Nilai yang Dipilih Fungsi & Catatan
Web Browsing >
Webview Cache Mode		 LOAD_DEFAULT PENTING: Jangan pilih LOAD_CACHE_ONLY atau LOAD_CACHE_ELSE_NETWORK karena akan membuat TV enggan mengambil data baru.
Web Browsing >
Clear Cache on Reload		 ENABLE (ON) Setiap kali halaman di-reload, memori cache WebView langsung dibersihkan dan aset ditarik segar dari Cloudflare.
Web Browsing >
Enable DOM Storage		 ENABLE (ON) Wajib aktif untuk menyimpan preferensi sesi lokal di memori TV.
Web Browsing >
Enable Third Party Cookies		 ENABLE (ON) Dibutuhkan untuk menjaga kontinuitas koneksi WebSocket Supabase Realtime.
Web Browsing >
Clear Cache Now		 [ KLIK 1 KALI ] Tekan tombol ini sekali saat pertama kali mengatur TV untuk membuang seluruh cache usang terdahulu.

3 Pengaturan Startup & Kiosk Mode (Otomatis & Stabil 24 Jam)

Membuat TV beroperasi layaknya media signage profesional: langsung menyala otomatis ke layar masjid tanpa gangguan status bar Android.

Menu di Fully Kiosk Nilai yang Dipilih Fungsi & Catatan
Web Content >
Start URL		 https://digitalaljihad.my.id/ Alamat web utama yang langsung dimuat saat aplikasi dibuka.
Device Management >
Launch on Boot		 ENABLE (ON) Ketika TV atau Android TV Box dihidupkan (misal setelah listrik padam), aplikasi otomatis terbuka sendiri.
Device Management >
Keep Screen On		 ENABLE (ON) Mencegah layar TV masuk mode tidur/sleep/mati saat sedang jam operasional.
Kiosk Mode >
Enable Kiosk Mode		 ENABLE (ON) Mengunci aplikasi agar jamaah atau anak-anak tidak bisa keluar ke menu Android sembarangan.
Web Browsing >
Pull to Refresh		 DISABLE (OFF) Matikan fitur geser ke bawah agar tampilan layar tidak bergeser tidak sengaja saat interaksi.
Web Auto Reload >
Periodic Web Reload		 86400 detik Otomatis refresh 1 kali per 24 jam (biasanya tengah malam) untuk menjaga performa memori TV tetap segar.
Web Auto Reload >
Reload on Network Reconnect		 ENABLE (ON) Jika Wi-Fi masjid sempat mati lalu tersambung lagi, TV otomatis reload tanpa perlu disentuh.
