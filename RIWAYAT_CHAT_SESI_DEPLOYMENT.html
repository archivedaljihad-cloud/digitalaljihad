Tentu, saya masih ingat dengan sangat jelas seluruh riwayat dan tempat deployment versi web dinamis (Laravel + PHP + Database) Anda sebelumnya:

1. Render.com (Platform Cloud Utama Versi Dinamis)

Ini adalah tempat hosting paling lama dan paling stabil saat menjalankan versi dinamis Laravel via Docker (Nginx + PHP-FPM):

  • Akun Render: Terhubung ke GitHub mydowndrive-ops (my.downdrive@gmail.com) dari repositori asal digitalaljihad001.
  • Alamat URL Layanan:
    • https://digital-aljihad.onrender.com/ (Service utama: digital.aljihad, Service ID: srv-daffllou01pc73a98acg. Sempat dipasang UptimeRobot ping 5 menit).
    • https://digitalaljihad001.onrender.com/ (Service generasi awal saat pertama kali setup, kemudian di-suspend).
    • https://digital-aljihad1.onrender.com/ (Service percobaan/cadangan).
  • Basis Data Cloud: Terhubung ke TiDB Cloud Serverless (gateway01.ap-southeast-1.prod.aws.tidbcloud.com:4000, database digitalv304).

2. Vercel (Uji Coba Serverless)

Sebelum pindah ke Render, Anda sempat mencoba mendeploy Laravel ke Vercel:

  • Alamat URL: Ditargetkan ke domain gratis bawaan Vercel (contoh: https://digitalaljihad001.vercel.app).
  • Konfigurasi Berkas: vercel.json & Dockerfile.vercel.
  • Koneksi Database: Sempat dicoba disambungkan ke Supabase PostgreSQL Pooler dan TiDB Cloud.
  • Catatan: Mengalami kendala runtime PHP serverless (build timeout, pop-up redeploy berbayar, dan prompt download file), sehingga beralih ke Render Docker.

3. Server Lokal / On-Premise (Komputer & Laptop Masjid)

  • Runtime: XAMPP / Laragon / php artisan serve.
  • Akses Lokal: http://127.0.0.1:8000 atau http://localhost/sholat_jumat.
  • Database: MySQL lokal (digitalv304.sql).

💡 Kilas Balik Transformasi: Karena pada versi dinamis di atas sering menghadapi masalah server tidur (cold start), kuota gratis terbatas, dan risiko database corrupt saat mati PLN tanpa UPS, sistem akhirnya direvolusi total 1000% menjadi Web Statis Modern di Cloudflare Workers (https://digitalaljihad.my.id/) dan Supabase Realtime.
