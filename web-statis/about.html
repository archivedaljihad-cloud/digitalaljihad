Studi Kasus Deploy Render

Perbandingan teknis: Web Statis Modern vs Web Laravel Dinamis Lama (Jika sama-sama di-deploy di platform Render)

Parameter / Aspek Kinerja Web Laravel Dinamis (Lama) Web Statis Modern (Saat Ini) 🏆
Tipe Layanan di Render Web Service (Docker/PHP) 🏆 Statis Menang Static Site (CDN Edge) — Gratis permanen tanpa batasan jam sewa.
Ukuran Web & Disk ~450 MB – 1.2 GB (Vendor PHP, framework, cache) 🏆 Hemat 96% ~25 MB – 45 MB (Murni aset statis HTML, CSS, JS, audio).
Waktu Build & Deploy 4 – 8 Menit (Composer install, migrate, optimize) 🏆 16x Lebih Cepat 10 – 30 Detik (Langsung publish tanpa kompilasi server).
Konsumsi RAM Server 200 MB – 450 MB (Rentan OOM di limit 512MB RAM) 🏆 Nol Risiko 0 MB (Serverless Edge, bebas crash Out-of-Memory).
Masalah Cold Start (Tidur) 50 – 90 Detik (Layar TV macet/loading saat bangun) 🏆 Instant 0 Detik (Nol Jeda) — Tidak pernah tidur 24 jam nonstop.
Kecepatan Respon (TTFB) 600 ms – 2.500 ms (Query database + render Blade) 🏆 Super Kilat 20 ms – 60 ms (Dihantarkan dari Cloudflare Edge Cache).
Ketahanan Internet Mati Layar Error / Putih (Gagal request HTTP ke server) 🏆 100% Mandiri Tetap Berjalan Normal via Cache LocalStorage & Client Engine.
Beban Hardware TV Box Sering jank/patah-patah akibat reload iframe berkala 🏆 60 FPS GPU Sangat ringan, hardware TV Box dingin & awet bertahun-tahun.
Kesimpulan Studi Perbandingan:

Layar TV masjid adalah perangkat yang berjalan 24 jam nonstop di lingkungan jaringan yang terkadang fluktuatif. Memindahkan sistem display dari server PHP dinamis ke Web Statis Modern berbasis Client-Side Engine membuktikan bahwa kesederhanaan arsitektur (*simplicity*) justru menghasilkan keandalan tertinggi: biaya operasional Rp 0, waktu tanggap tanpa jeda, serta tampilan visual yang tak pernah mengecewakan jamaah.

Panduan Pengoperasian Sistem

Petunjuk teknis pengoperasian TV display, mode sholat, dan kajian

A. Layar TV Utama (Di Dalam Masjid):

  1. Buka aplikasi browser (Chrome / Edge / Browser TV) pada Smart TV atau Android Box.
  2. Ketik alamat website utama masjid: https://digitalaljihad.my.id/.
  3. Tekan tombol F11 pada keyboard (atau aktifkan mode Fullscreen / Kiosk) untuk menyembunyikan address bar.
  4. Layar akan otomatis berputar menampilkan jadwal sholat, pengumuman, siaran live, dan laporan kas secara bergantian.

B. Layar TV Luar / Serambi Masjid:

  1. Gunakan alamat khusus TV Luar: https://digitalaljihad.my.id/slides/live-mimbar.html.
  2. Di jam biasa berputar menampilkan informasi umum. Saat Khutbah Jum'at tiba, layar otomatis beralih menampilkan siaran langsung mimbar masjid.
  1. Fase Tarhim: Audio tarhim otomatis berbunyi beberapa menit sebelum waktu adzan tiba.
  2. Fase Adzan: Rotasi TV berhenti, menampilkan pengingat adzan berkumandang.
  3. Fase Iqamah: Hitung mundur jeda sholat sunnah hingga iqamah ditegakkan.
  4. Fase Sholat: Layar TV otomatis menjadi gelap syahdu bertuliskan "Luruskan dan Rapatkan Shaf Anda".
  5. Khusus Sholat Jum'at: Layar menampilkan 4 kartu petugas resmi (Khatib, Imam, Muadzin, Bilal) serta hadits larangan berbicara saat khutbah.
  6. Selesai Sholat: Layar TV kembali berotasi normal menampilkan informasi masjid secara otomatis.

Setiap hari Sabtu malam, sistem akan otomatis beralih menampilkan poster pengajian:

  • Jam Mulai Otomatis: Dimulai ba'da Maghrib (pukul 18:25) hingga waktu adzan Isya tiba.
  • Tanya Jawab Digital: Menampilkan QR Code interaktif sehingga jamaah dapat mengirimkan pertanyaan dari smartphone tanpa perlu mikrofon.
  • Manajemen Siklus 5 Pekan: Pengurus dapat mengisi jadwal pemateri dan kitab untuk 5 pekan sekaligus di panel admin.
