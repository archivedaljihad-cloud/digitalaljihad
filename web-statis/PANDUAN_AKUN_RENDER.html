3. Panduan Langkah Demi Langkah Mematikan / Menghapus Permanen di Render

Karena Anda sudah membuka halaman Settings dari servis digital.aljihad tersebut, ikuti langkah berikut:

  1. Pada layar Settings yang sedang terbuka di komputer Anda, gulir (scroll) terus ke bagian paling bawah halaman.
  2. Di bagian paling bawah, Anda akan menemukan kotak bergaris merah bernama Danger Zone.
  3. Di dalam kotak Danger Zone terdapat dua tombol pilihan:
    • Suspend Web Service: Mematikan sementara service.
    • Delete Web Service (SANGAT DIREKOMENDASIKAN): Menghapus servis secara permanen agar akun bersih dan tidak menimbulkan kebingungan di masa depan.
  4. Tahap Konfirmasi (Penting):
    • Klik salah satu tombol di atas (disarankan Delete Web Service).
    • Akan muncul jendela pop-up konfirmasi.
    • Ketikkan teks konfirmasi yang diminta oleh Render (biasanya nama servicenya: digital.aljihad).
    • Klik tombol merah konfirmasi (Delete / Confirm).
  5. Selesai! Badge ✓ Live akan langsung hilang, dan URL digital-aljihad.onrender.com akan langsung mati total saat itu juga.
