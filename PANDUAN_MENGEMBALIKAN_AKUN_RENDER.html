2. Langkah-Langkah Mengaktifkan Kembali (3 Langkah Mudah)

LANGKAH 1: Unsuspend / Resume Web Service di Dashboard Render
  • Buka dashboard Render di browser: https://dashboard.render.com.
  • Login menggunakan akun mydowndrive-ops (atau email my.downdrive@gmail.com).
  • Buka service pertama: digitalaljihad1. Masuk ke tab Settings, gulir ke paling bawah, lalu klik tombol Resume Service / Unsuspend.
  • Lakukan hal yang sama untuk service kedua: digital-aljihad.
  • Pastikan kedua service telah berubah statusnya menjadi bertanda hijau ✓ Live.
LANGKAH 2: Mengubah Saklar MODE_PERBAIKAN di GitHub
  • Buka repositori: https://github.com/mydowndrive-ops/aljihad.
  • Klik pada berkas index.html, lalu klik ikon pensil (Edit this file).
  • Cari baris saklar utama (sekitar baris ke-201):
    const MODE_PERBAIKAN = true;
  • Ubah kata true menjadi false sehingga menjadi:
    const MODE_PERBAIKAN = false;
  • Klik tombol hijau Commit changes... di pojok kanan atas untuk menyimpan.
LANGKAH 3: Pengujian di Layar TV / Browser
  • Buka tautan: https://mydowndrive-ops.github.io/aljihad/ di browser laptop atau TV.
  • Layar akan menampilkan logo Masjid Al-Jihad dengan animasi putar (splash screen).
  • Setelah 5–15 detik (waktu bangun server Render), tampilan akan otomatis terbuka dan menyiarkan display TV digital secara normal.

3. Perbandingan Mode Perbaikan vs Mode Normal

🔴 Mode Perbaikan (Saat Ini)

const MODE_PERBAIKAN = true;

Menampilkan kartu informasi pemeliharaan dan jam digital aktif. Iframe dinonaktifkan agar tidak muncul error 503 Render.

🟢 Mode Normal (Kedua Render Aktif)

const MODE_PERBAIKAN = false;

Iframe langsung memuat Server 1 (tgl 1-15) atau Server 2 (tgl 16-31). Fitur switch otomatis tengah malam aktif.

4. Fitur Otomasi 24 Jam

Auto-Switch Tengah Malam Otomatis berpindah server di jam 00:00 tanggal 16 tanpa perlu matikan/restart TV.
Penyegaran Memori (03:15 WIB) Soft reload harian sebelum waktu Subuh agar Smart TV/STB tidak lag.
Anti-Freeze Logo Dilengkapi penahan error sehingga jaringan bermasalah tidak akan membuat layar blank hitam.
