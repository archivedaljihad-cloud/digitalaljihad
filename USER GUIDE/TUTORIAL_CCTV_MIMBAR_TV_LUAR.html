Menghubungkan CCTV Live Mimbar (Kabel BNC via DVR) ke TV Luar Masjid
Panduan Resmi Operasional Display Masjid Digital • Sholat Jum'at, Idul Fitri & Idul Adha

1. Gambaran Alur Sistem (Arsitektur Jaringan)

Sistem ini memanfaatkan kamera CCTV analog kabel BNC yang sudah ada di mimbar/mihrab tanpa perlu membeli kamera baru. DVR bertindak sebagai encoder digital lokal.

[ Kamera Mimbar (Kabel BNC) ] │ (Kabel Coaxial BNC ke DVR Masjid) ▼ [ DVR CCTV Masjid ] ──(Kabel LAN RJ45)──▶ [ Router Wi-Fi Masjid ] │ ├──▶ [ Laptop / PC Server Masjid ] (Laravel) │ └──▶ [ Smart TV / TV Box di Luar ] (/tv-outdoor)

2. Langkah 1: Sambungkan DVR ke Router Masjid

  1. Ambil kabel jaringan LAN (kabel RJ45 standar).
  2. Tancapkan ujung satu ke port LAN / Network di bagian belakang mesin DVR CCTV.
  3. Tancapkan ujung lainnya ke port LAN pada Router Wi-Fi Masjid (atau Switch Hub).
  4. Pastikan lampu LED port LAN di belakang DVR menyala/berkedip hijau atau oranye.

3. Langkah 2: Cari Tahu Alamat IP DVR Masjid

  1. Di layar monitor CCTV masjid, buka menu: Main Menu > Configuration > Network (Jaringan).
  2. Catat IP Address DVR Anda (Contoh: 192.168.1.100 atau 192.168.1.50).
  3. Catat Username (biasanya admin) dan Password DVR Anda.
  4. Perhatikan kamera mimbar tercolok di port nomor berapa (misal: Channel 1).

4. Langkah 3: Format Alamat Stream RTSP Lokal

DVR CCTV modern otomatis menyediakan siaran RTSP untuk setiap channel kamera:

Merk DVR CCTV Format URL RTSP Lokal Keterangan
Hikvision / Hilook rtsp://admin:Pass@192.168.1.100:554/Streaming/Channels/101 Channel 1 Resolusi Utama (HD)
Dahua / IMOU rtsp://admin:Pass@192.168.1.100:554/cam/realmonitor?channel=1&subtype=0 Channel 1 Resolusi Utama
XMeye / SPC / OEM rtsp://admin:Pass@192.168.1.100:554/user=admin_password=Pass_channel=1_stream=0.sdp Channel 1 Main Stream
Avtech rtsp://admin:Pass@192.168.1.100:554/live/ch0 Channel 1
Catatan: Ganti admin, Pass, dan 192.168.1.100 dengan username, password, dan IP DVR asli masjid Anda.

5. Langkah 4: Menjalankan RTSP-to-Web Converter di Laptop Server (0 Delay)

Agar browser di TV dapat memutar RTSP tanpa delay dan tanpa kuota internet, gunakan software gratis dan sangat ringan bernama go2rtc (tanpa instalasi):

  1. Download go2rtc dari tautan: https://github.com/AlexxIT/go2rtc/releases (pilih go2rtc_win64.zip).
  2. Ekstrak foldernya (contoh: di C:\go2rtc\).
  3. Buat file teks bernama go2rtc.yaml di folder yang sama, lalu isi:
    streams: mimbar: rtsp://admin:Password123@192.168.1.100:554/Streaming/Channels/101
  4. Klik dua kali file go2rtc.exe untuk menjalankannya.
  5. Siaran kamera mimbar kini sudah aktif di alamat web lokal:
    http://[IP-Laptop-Server]:1984/stream.html?src=mimbar

6. Langkah 5: Masukkan Pengaturan di Dashboard Admin Masjid

  1. Buka dashboard admin masjid: http://localhost:8000/settings
  2. Klik tab CCTV Mimbar & TV Luar.
  3. Geser saklar Aktifkan Fitur CCTV Mimbar ke posisi AKTIF.
  4. Geser saklar Otomatis Beralih saat Khutbah ke posisi AKTIF.
  5. Masukkan URL stream di kolom: http://[IP-Laptop-Server]:1984/stream.html?src=mimbar
  6. Klik tombol Simpan Semua Perubahan.

7. Langkah 6: Cara Menyalakan TV di Luar Masjid

  1. Nyalakan Smart TV atau Android TV Box di serambi / halaman luar masjid.
  2. Pastikan TV terhubung ke Wi-Fi / kabel LAN yang sama dengan laptop server.
  3. Buka aplikasi Browser di TV, lalu ketik alamat:
    http://[IP-Laptop-Server]:8000/tv-outdoor
  4. Tekan tombol Layar Penuh (Fullscreen / F11).
Perilaku Otomatis TV Luar:
  • Hari & Jam Biasa: TV luar memutar rotasi display jadwal sholat, pengumuman, keuangan, dan slide infaq secara bergantian.
  • Saat Khutbah Jum'at / Sholat Ied: TV luar secara otomatis langsung beralih menyiarkan wajah khatib di mimbar lengkap dengan nama khatib, jam digital, dan hadits larangan berbicara saat khutbah!
  • Setelah Sholat Selesai: TV luar otomatis kembali memutar informasi display masjid normal.

8. Tips Uji Coba Cepat (Simulasi)

Anda bisa menguji tampilan siaran mimbar di TV luar kapan saja tanpa harus menunggu hari Jum'at tiba dengan membuka:

http://localhost:8000/tv-outdoor?mimbar=1
